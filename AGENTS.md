# Governance public-edition authority

- Mandatory founding conduct: [FCIS Goal Fidelity and Non-Invention](https://github.com/Fountain-Coach/.github/blob/main/docs/FCIS-Non-Invention-and-Goal-Fidelity.md) and the Chapter 07 amendment. Preserve the writer's outcome; label speculation; refuse invented blockers and moving DoD. A new dependency needs a reproducible failed operation, an applicable existing requirement and the smallest necessary correction.
- This repository is authoritative for **governance.fountain.coach**, not a
  selected Fountain Press Governance book.
- Never change prose, chapter ordering, IDs, rights, statuses, route-map or
  referenced figures merely to improve the appearance of a book.
- Every edit that changes a public asset requires source review, a Git commit,
  checksum regeneration, validation, and independently authorized deployment.
- Site payload lives under site/. Never publish repo scripts, docs or Git files.
- Do not copy from an estate workspace over the repo without checking
  provenance; the estate-local copy is now downstream.
- When syncing to the estate, verify destination and preserve unrelated hosts.
- No GitHub Actions, auto-deploy-on-push, private secrets or test fixtures
  exposed as accepted publication.
- Complete published-domain parity is an acceptance requirement. Do not claim
  deployment parity after source edits unless the live HTTPS witness passes.
- The live snapshot knowingly has six routes omitted from route-manifest.json;
  that inherited inconsistency is not authority to drop those files.
